Pembayaran QRIS

Pasang Server Key Midtrans milik toko Anda. Dana pembayaran masuk langsung ke rekening Anda, tidak melewati pihak lain. Setelah terpasang, pembayaran terkonfirmasi otomatis dan kasir tidak perlu mengecek mutasi.

Dari dashboard Midtrans → Settings → Access Keys. Setelah disimpan, key tidak dapat ditampilkan kembali — hanya bisa diganti.
Pastikan sesuai dengan key yang Anda pakai. Key sandbox tidak bekerja di production.

Printer Struk Bluetooth

Belum terhubung
Hubungkan printer untuk mencetak struk langsung.
Cetak otomatis setelah transaksi
Struk langsung keluar tanpa menekan tombol cetak.
Printer saya tidak terdeteksi

Periksa berurutan:

  1. Printer menyala dan lampunya tidak berkedip cepat (berkedip = sedang pairing)
  2. Printer tidak sedang terhubung ke HP atau aplikasi lain
  3. Bluetooth komputer atau HP aktif
  4. Jarak di bawah 5 meter

Kalau tetap tidak muncul, kemungkinan printer Anda hanya mendukung Bluetooth Classic (SPP). Browser tidak bisa menjangkau jenis itu — hanya printer dengan Bluetooth 4.0 / BLE yang bisa. Cek kemasan atau spesifikasi printer Anda.

Sebagai cadangan, struk tetap bisa dicetak lewat dialog print browser.
